# Dashboard Plan

## Key Metrics
- Total Orders
- SLA Breach %
- Average Delivery Time
- Orders by Status
- Delay Analysis
- Bottleneck Identification

## KPIs
- Total Orders
- Orders Delivered Late
- SLA Breach %
- Average Delay (days)
- Delivery Efficiency Score

## Planned Visuals
- Line chart: Orders over time
- Bar chart: SLA breaches by product
- Table: Orders with delay details
- Pie chart: Order status distribution
- KPI cards (Total orders, SLA %, Avg delay)

## Data Model
- Orders table (from sample_orders.csv)
- Optional future tables:
  - Customers
  - Products
  - SLA reference table

## Business Questions
1. How many orders breach SLA deadlines?
2. What product categories face the highest delays?
3. Are delays increasing or decreasing over time?
4. What are the main bottlenecks in the process?
